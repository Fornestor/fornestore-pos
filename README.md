# fornestore-pos
Fornestore POS adalah aplikasi kasir offline dan operasional toko untuk Windows, berbasis Electron, React, Vite, dan TypeScript. Aplikasi ini membantu mencatat penjualan, stok, restok, pelanggan, promo, laporan, pecah grosir, backup, restore, dan reset data secara lokal tanpa ketergantungan internet.
